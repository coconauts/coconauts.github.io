# Coconauts Tech Blog - Context Summary

This document provides comprehensive context about the Coconauts tech blog (https://coconauts.net/) for better understanding of the project's scope, technologies, and content.

## Blog Overview

**Coconauts** is a technical blog created by a Spanish duo of makers and developers, focused on hardware-software integration projects, game development, and innovative technology experiments. The blog was active from 2013-2017 and contains 80+ detailed technical posts.

**Authors:**
- **Javier Rengel** (rephus): Hardware specialist, Arduino/embedded systems expert
- **Mar Bartolome**: Software developer, game development and audio specialist

**Platform:** Jekyll/Octopress static site hosted on GitHub Pages

## Core Subject Areas

### 1. Hardware Development (Primary Focus)
- **Arduino Projects**: Extensive tutorials, comparisons, and project walkthroughs
- **Raspberry Pi Integration**: Sensor networks, automation, web interfaces
- **Wearable Technology**: The flagship **Watchduino** project (DIY smartwatch, versions 1.0-2.0)
- **Home Automation**: Energenie sockets, LED systems, automated plant watering
- **Sensor Networks**: Wireless RF24 radio modules for environmental monitoring
- **IoT Development**: ESP8266 WiFi-enabled projects

### 2. Game Development (Secondary Focus)
- **Mobile Games**: Android development using LibGDX
- **Unity3D Projects**: 3D games, VR experiments, engine comparisons
- **2D Gaming**: Framework analysis (Defold, Phaser, Game Maker)
- **Retro Gaming**: Retrophies project, arcade development
- **Game Audio**: Chiptune music creation, 8-bit sound effects

### 3. Software Development
- **Web Development**: Node.js applications, JavaScript tools
- **DevOps**: Custom CI/CD solutions, Jenkins automation
- **Mobile Development**: Android apps, Cordova plugins, Bluetooth communication
- **APIs**: Spotify integration, GitHub tools, web scraping
